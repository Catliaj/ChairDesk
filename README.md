# ChairDesk

**Program Chair Analytics & Decision-Support System (BAT 405 – Integrated Case Study)**

ChairDesk integrates data from the **Student and Faculty Portal** and **Student Evaluation of Teaching Effectiveness (SETE)** into a responsive one-page analytics dashboard for Program Chairs.

- **Live Dashboard:** `index.html`
- **Authors:** AJ E. Catli, Roel L Bendaña
